The TryPost MCP server exposes **83 tools**. This page lists all of them, grouped like the app: posts, ideas, analytics, social accounts and the queue, repurpose, labels, signatures, webhooks, API keys, workspace and platform rules.

Tool names are exactly what your assistant sees (kebab-case with a `-tool` suffix). Every tool acts on the one workspace you picked when you authorized the connection. Times in arguments are ISO 8601 (without an offset they are read as UTC). In responses, post, idea, label, signature, note and workspace times are UTC `Y-m-d H:i:s`; webhooks, API keys, repurposes, free slots and the upload `expires_at` are ISO 8601 with an offset.

<Note>
  There is no MCP tool that writes a caption, an image or a video for you. Your assistant writes the text itself and sends it with `create-post-tool`; the built-in AI writing assistant is available in the web app. Repurpose may shorten captions with AI in the background, including for rules created through MCP.
</Note>

## Recommended workflow

### Create and publish a post

1. **`get-workspace-tool`**: check `me.requires_approval`. When it is `true`, anything you schedule, queue or publish waits for approval (see [Approvals](#approvals)).
2. **`list-social-accounts-tool`**: pick the channel. Note its `max_content_length`, `timezone` and `has_posting_schedule`.
3. **Settle the time zone.** Times you say in conversation ("tomorrow at 9am") are local, but every tool takes UTC and no tool returns your own time zone. Tell the assistant your time zone, or let it use the channel's `timezone` from the previous step. It must send `scheduled_at` with an offset or in UTC.
4. **`list-content-types-tool`**: pick a `content_type` and read its media rules, hashtag limit and `required_meta`.
5. Resolve required settings: **`get-tiktok-creator-info-tool`** (TikTok `privacy_level`), **`list-pinterest-boards-tool`** or **`create-pinterest-board-tool`** (Pinterest `board_id`), **`list-discord-channels-tool`** (Discord `channel_id`).
6. Get media in: a public URL goes straight into `media[]`. For a local file, call **`request-media-upload-tool`**, upload the file with `curl -F media=@file "<upload_url>"` within 15 minutes (a CLI agent can run it; in a web or mobile chat you run it yourself), then pass the `upload_token`. Chat apps that run in the cloud can only use files at a public URL or the `id` of media already in TryPost.
7. **`create-post-tool`** (one channel) or **`create-posts-tool`** (several channels, one post each). Send `status: draft` to review first, or `scheduled` / `publishing` to go straight out.
8. **`preview-post-tool`**: see the exact text each network gets.
9. **`publish-post-tool`**: publish a draft now, at a time, or into the queue.
10. **`get-post-metrics-tool`**: read the saved analytics after it is published.

### Use the queue

1. **`get-posting-schedule-tool`**: see the channel's posting times (set them with `update-posting-schedule-tool`, `generate-posting-schedule-tool` or `copy-posting-schedule-tool` if it has none).
2. Create with `status: scheduled` and `queue: next` (first free slot) or `queue: top` (first slot, shifting queued posts back).
3. To take one exact slot: **`list-free-slots-tool`**, then `create-post-tool` with `queue_slot`, or **`move-post-to-slot-tool`** for an existing post.
4. **`reorder-queue-tool`**: swap queued posts among the slots they already hold.

How the queue keeps slots is explained in [Queue](/knowledge-base/publish/queue).

## Access and permissions

MCP accepts every member of the workspace, not only admins (the [REST API](/api-reference/introduction) only accepts admin API keys). Each tool then checks the same permission as the matching page in the app:

| Who | Can call |
|-----|----------|
| **Any member** | Every Posts tool except approve, reject and set recurrence (including notes and media); ideas and idea stages; analytics; labels; signatures; `list-social-accounts-tool`, `get-posting-schedule-tool`, `list-free-slots-tool`, Pinterest boards, Discord channels, Instagram audio, TikTok creator info; `get-workspace-tool`; `list-content-types-tool` |
| **Members who publish directly** (owner, admins, and members who do not need approval) | `approve-post-tool`, `reject-post-tool`, `set-post-recurrence-tool`, `reorder-queue-tool`, `move-post-to-slot-tool`, every repurpose tool (reads included) |
| **Admins** (and the account owner) | `update-posting-schedule-tool`, `generate-posting-schedule-tool`, `copy-posting-schedule-tool`, every webhook tool and every API key tool (reads included) |

A refused call returns a tool error such as `This action is unauthorized.` Items from another workspace answer as not found (`Post not found.`, `Repurpose not found.`, …). See [Members and permissions](/knowledge-base/settings/members-and-permissions).

### Approvals

A member who needs approval can create and edit posts. When they schedule, queue or publish, TryPost stores the post with status `pending_approval` instead, and it waits for `approve-post-tool` or `reject-post-tool` from a member who publishes directly. The same happens when such a member edits an approved scheduled post or attaches media to it. A pending post is visible only to approvers and to the member who asked. A member who needs approval may delete only posts they wrote, or their own requests that are still pending. See [Approvals](/knowledge-base/publish/approvals).

### Before a post can be scheduled or published

Drafts may be incomplete. Scheduling, queueing or publishing needs:

- Text or media.
- TikTok `meta.privacy_level`, one of the `privacy_level_options` from `get-tiktok-creator-info-tool`.
- Pinterest `meta.board_id` and Discord `meta.channel_id`.
- Google Business: `meta.event` with a title and start/end dates on `EVENT` and `OFFER` (the end may not precede the start). A `call_to_action` needs a `url` unless its `action_type` is `NONE` or `CALL`, and offers take no call to action.
- Thread replies (X, Bluesky, Mastodon): each reply that is not a poll has text or media, and each reply fits the account limit.
- YouTube: a title (`meta.title`, or the first line of the text).
- X poll (`x_poll`, or a reply with `poll`): a question, at least 2 `poll.options` and `poll.duration_minutes`.

`list-content-types-tool` lists the unconditional ones (TikTok, Pinterest, Discord) per platform as `required_meta`. Media rules (count, size, duration, aspect ratio, GIF and MOV) are checked at the same moment, never on a draft. The exception is X polls: on an `x_poll` post or a reply poll, media, a repeated choice, more than 4 choices, a choice over 25 characters or a `duration_minutes` outside 5–10080 is refused on every save, drafts included.

### Media

Every `media[]` item gives exactly one of:

| Key | Use |
|-----|-----|
| `url` | A public `http(s)` URL that serves the file itself. Redirects are not followed and web pages are refused; the download must finish within 20 seconds. |
| `upload_token` | A file uploaded with `request-media-upload-tool`. A token is spent by the first post that takes it; uploads are kept 24 hours. |
| `id` | A media item already in this workspace (from a post's `media`). It is copied for the post. On update, send the current ids in a new order to reorder, and leave one out to remove it. |

Optional per item: `alt` (images), and `meta` with `alt_text` (max 2000; it wins over `alt`), `user_tags` (Instagram feed images, up to 20 `{username, x, y}`) and `cover_offset_ms` (video cover frame, where `supports_video_cover`). `attach-media-from-upload-tool` and `attach-media-from-url-tool` take the same `alt` and `meta`. A PDF must be the only attachment. The first item is the cover of a carousel.

Accepted files: JPEG, PNG, GIF and WebP images (HEIC and HEIF when the server can convert them), MP4 and MOV videos, and PDF. Server ceilings by default: **10 MB** and 67 megapixels per image, **1 GB** per video, **100 MB** per PDF. Each network's own, usually smaller, limits apply when the post is scheduled or published. The signed upload URL works once and expires after 15 minutes. More in [Media uploads](/api-reference/guides/media-uploads).

### Per-platform `meta`

`meta` holds the settings of the post's channel. The same keys work on the REST API ([Posting guide](/api-reference/guides/posting)). Unknown keys are dropped. Enum values are exact JSON strings.

| Platform | Keys | Required to schedule or publish |
|----------|------|---------------------------------|
| X, Bluesky, Mastodon | `thread_replies`: up to 24 replies published under the post, each `{text, media}` (up to 4 media items per reply) or a plain string. Each reply fits the account's text limit. X also takes `is_ai_generated` | — |
| X | `poll` on content type `x_poll`: `{options, duration_minutes}`, 2 to 4 different choices of 1–25 characters and 5–10080 minutes. The post text is the question (max 280, even with long posts). A poll takes no media, drafts included, and media tools refuse to attach to one. `poll` is merged key by key on update; `options` replaces the list. A reply in `thread_replies` can be `{text, poll}` under the same rules | `poll.options` (2 or more), `poll.duration_minutes` and a question |
| Mastodon | `spoiler_text` (content warning, max 500; counts toward the 500 characters and is repeated on every reply) | — |
| TikTok | `privacy_level` (`PUBLIC_TO_EVERYONE` \| `MUTUAL_FOLLOW_FRIENDS` \| `FOLLOWER_OF_CREATOR` \| `SELF_ONLY`); `allow_comments`, `disclose`, `brand_content_toggle`, `brand_organic_toggle`; on `tiktok_video` also `allow_duet`, `allow_stitch`, `is_aigc`; on `tiktok_photo` also `auto_add_music`. `SELF_ONLY` cannot be combined with `brand_content_toggle` | `privacy_level` |
| Pinterest | `board_id`, `title` (max 100), `link` | `board_id` |
| Discord | `channel_id`, `mentions` (`[{token, label}]`), `embeds` (up to 10 `{title, description, url, image, color}`). The channel name is filled by TryPost from the channel list read in the last 5 minutes; a `channel_name` you send is ignored | `channel_id` |
| YouTube | `title` (max 100, no `<` or `>`), `description` (max 5000 bytes), `category_id` (default `22`), `privacy_status` (`public` \| `unlisted` \| `private`), `license`, `notify_subscribers`, `embeddable`, `made_for_kids`, `is_ai_generated` | A title, or text to derive it from |
| Instagram | `is_ai_generated`; `collaborators` (up to 3 usernames, feed posts, carousels and reels, not stories; the post shows on a collaborator's profile only after they accept the invite in the Instagram app, and a username that does not exist is only refused when the post publishes); on `instagram_reel` also `share_to_feed` (default `true`), `trial_graduation` (`MANUAL` \| `SS_PERFORMANCE`, not with `collaborators`, only on accounts where Instagram offers trial reels) and `audio` (`instagram-facebook` accounts only: `{id, title, artist, cover_url, preview_url, audio_volume, video_volume}`, `id` from `search-instagram-audio-tool` as a string of digits, volumes 0–100, default 100). People tags and a video cover are per media item (see [Media](#media)). At most 5 hashtags | `audio.id` when `audio` is set; no `collaborators` on a trial reel |
| Threads | `topic_tag` (1–50 characters, no `.` or `&`). Content type `threads_ghost_post` is a text-only post archived after 24 hours | — |
| Facebook, Bluesky, LinkedIn | `link_preview` (default `true`; `false` publishes the link without a preview card) | — |
| LinkedIn, LinkedIn Page | `document_title` (max 300, for PDF document posts) | — |
| Google Business | `topic_type` (`STANDARD` \| `EVENT` \| `OFFER`), `call_to_action` `{action_type, url}`, `event` `{title, start_date, end_date, start_time, end_time}`, `offer` `{coupon_code, redeem_online_url, terms_conditions}` | `event` on `EVENT`/`OFFER`; `call_to_action.url` unless `NONE`/`CALL`. `action_type` is one of `NONE`, `BOOK`, `ORDER`, `SHOP`, `LEARN_MORE`, `SIGN_UP`, `CALL`; offers take no call to action |
| Telegram, Facebook reels and stories | none | — |

Instagram and Facebook stories publish no text.

## Notes

- **Lists are paginated** with the app page size (25 today; read `per_page` rather than assuming it). Pass `page`; responses carry `total`, `per_page`, `current_page` and `last_page` next to the rows.
- **Errors** come back as tool errors with a message (`Post not found.`, `This action is unauthorized.`, or the validation message). When the queue of a channel is busy, retry in a moment.
- **Confirmations**: every tool tells the client whether it only reads, whether it changes or removes existing data, and whether it reaches outside TryPost. Read-only tools run without asking in most clients. Tools that change or remove data, publish, approve or reject, send email or replay a webhook are marked destructive, so clients ask you first; purely additive tools (creating an idea, idea stage, label, signature, API key, repurpose, webhook or Pinterest board, and requesting an upload) are not. Tools that can publish to public networks, fetch a URL, call a webhook endpoint or read Instagram's audio catalog are marked as reaching outside TryPost.
- **Not available through MCP**: AI generation, connecting or disconnecting channels, turning ideas into posts, templates, members and invites, billing. Use the web app for these.
